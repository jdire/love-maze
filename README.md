# Love Maze ♥

An 8-bit style maze game themed on love with peppy vibes. Navigate through increasingly complex mazes, collect hearts, and reach the golden endzone to progress!

## Features

- **8-bit Pixel Art**: Retro aesthetic with heart-themed graphics
- **Procedural Mazes**: Each level generates a unique maze
- **Progressive Difficulty**: Mazes grow larger with each level
- **Collectibles**: Gather hearts for bonus points
- **Love Theme**: Pink and red color palette with heart motifs

## Controls

- **Arrow Keys** or **WASD**: Move your heart character
- **R**: Reset current level
- **ESC**: Quit game

## Installation

1. Install Python 3.x
2. Install Pygame:
   ```bash
   pip install pygame
   ```

## Running the Game

```bash
python main.py
```

## Gameplay

- Navigate the pink maze as a cute heart character
- Collect floating hearts for bonus points
- Reach the golden heart endzone to advance
- Each level increases maze complexity

## Technical Details

- Built with Python and Pygame
- Recursive backtracking maze generation
- Collision detection system
- 8-bit styled graphics rendering
